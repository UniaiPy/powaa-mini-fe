1. **核心函数设计**：

   * 在app.js中创建`checkAndSendFriendRequest()`函数，用于统一检查并发送好友请求

   * 包含逻辑：检查登录状态、用户信息完整性、AI训练状态、sharedUserId有效性、是否已发送过请求

2. **触发时机**：

   * **profile.js**：在所有保存用户信息的方法成功后调用

     * `saveProfileEdit()` (个人简介保存)

     * `saveContactEdit()` (联系信息保存)

     * `saveWechatInfoToServer()` (微信信息保存)

   * **avatar.js**：在消息接收回调中检查AI训练状态

     * `onMessageReceived()`：每次接收消息后检查AI训练状态，若完成则触发好友请求

   * **app.js**：在app显示时全局检查

     * `onShow()`：确保用户从其他页面返回时能触发检查

3. **检查条件**：

   * 用户已登录 (`app.isLoggedIn()`)

   * 用户信息完整 (`app.checkUserInfoComplete({redirect: false})`)

   * AI训练已完成 (调用`/api/ai-avatars/is_trained`接口，status为'active')

   * 存在有效的sharedUserId (从全局变量或本地缓存获取)

   * 未发送过好友请求 (`!wx.getStorageSync(\`sentFriendRequest\_${sharedUserId}\`)\`)

4. **具体实现步骤**：

   * **第一步**：在app.js中创建`checkAndSendFriendRequest()`函数

   * **第二步**：在profile.js的各个保存方法成功回调中添加调用

   * **第三步**：在avatar.js的`onMessageReceived()`方法中添加AI训练状态检查和调用

   * **第四步**：在app.js的`onShow()`生命周期中添加全局检查

5. **代码实现细节**：

   * **app.js新增函数**：

     ```javascript
     checkAndSendFriendRequest: function() {
       const sharedUserId = this.globalData.sharedUserId || wx.getStorageSync('sharedUserId');
       if (!sharedUserId) return;
       
       if (!this.isLoggedIn()) return;
       if (!this.checkUserInfoComplete({redirect: false})) return;
       
       // 检查AI训练状态
       this.request({
         url: '/api/ai-avatars/is_trained',
         method: 'GET',
         success: (res) => {
           if (res.success && res.data.status === 'active') {
             // 检查是否已发送过请求
             const hasSent = wx.getStorageSync(`sentFriendRequest_${sharedUserId}`);
             if (!hasSent) {
               this.sendAutoFriendRequest(sharedUserId);
             }
           }
         }
       });
     }
     ```

   * **profile.js保存方法调用**：

     ```javascript
     // 在saveProfileEdit()、saveContactEdit()、saveSocialMediaEdit()、saveWechatInfoToServer()的success回调中添加
     app.checkAndSendFriendRequest();
     ```

   * **avatar.js消息接收处理**：

     ```javascript
     // 在onMessageReceived()方法中添加
     const app = getApp();
     app.request({
       url: '/api/ai-avatars/is_trained',
       method: 'GET',
       success: (res) => {
         if (res.success && res.data.status === 'active') {
           app.checkAndSendFriendRequest();
         }
       }
     });
     ```
