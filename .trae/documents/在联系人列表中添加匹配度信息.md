7. **性能考虑**：

   * 批量获取匹配度，减少API调用次数

   * 合理处理异步请求，确保数据加载完成后再更新UI

8. **代码示例**：

   ```javascript
   // 提取用户ID列表
   const userIds = contactsList.map(contact => contact.userId);

   // 调用匹配度API
   app.request({
     url: '/api/users/batch',
     method: 'POST',
     data: {
       user_ids: userIds
     },
     success: (res) => {
       if (res.success && res.data) {
         // 合并匹配度数据
         const updatedContacts = contactsList.map(contact => {
           const matchData = res.data.find(item => item.user_id === contact.userId);
           return {
             ...contact,
             matchPercent: matchData ? matchData.match_percent : 0
           };
         });
         
         // 更新UI
         this.setData({
           contactsList: updatedContacts
         });
       }
     },
     fail: (error) => {
       console.error('获取匹配度失败:', error);
       // 失败时仍显示联系人列表，匹配度默认为0
       this.setData({
         contactsList: contactsList.map(contact => ({
           ...contact,
           matchPercent: 0
         }))
       });
     }
   });
   ```
