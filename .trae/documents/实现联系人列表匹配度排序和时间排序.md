# 实现联系人列表匹配度排序和时间排序

## 一、需求分析
1. **时间排序**：默认情况下，联系人列表应按照最后一条消息的时间倒序排列
2. **匹配度排序**：在搜索时，搜索结果应根据与关键词的匹配程度排序，匹配度高的排在前面

## 二、实现思路

### 1. 时间排序实现
- **修改 `processConversationList` 方法**：在生成联系人列表后，添加时间排序逻辑
- **排序依据**：使用 `lastMessage.lastTime` 字段，按照时间戳倒序排列

### 2. 匹配度排序实现
- **修改搜索相关方法**：在 `searchContacts` 和 `performLocalSearch` 方法中添加匹配度计算
- **匹配度计算规则**：
  - 完全匹配：最高优先级
  - 开头匹配：次之
  - 包含匹配：再次之
  - 多字段匹配：根据匹配字段数量加权
- **搜索结果排序**：根据匹配度分数倒序排列

## 三、具体实现步骤

### 步骤1：实现时间排序
1. 在 `processConversationList` 方法的第936行后，添加时间排序逻辑
2. 使用 `Array.sort()` 方法，按照 `lastMessage.lastTime` 倒序排列

### 步骤2：实现匹配度计算
1. 添加 `calculateMatchScore` 辅助方法，用于计算匹配度分数
2. 该方法接收搜索关键词和联系人对象，返回匹配度分数

### 步骤3：修改搜索方法
1. 修改 `searchContacts` 方法，为搜索结果添加匹配度分数
2. 修改 `performLocalSearch` 方法，为搜索结果添加匹配度分数
3. 对搜索结果按照匹配度分数倒序排列

### 步骤4：优化搜索结果处理
1. 确保搜索结果包含足够的信息，以便进行匹配度计算
2. 优化匹配算法，提高搜索效率

## 七、实现代码示例

```javascript
// 1. 时间排序实现
const sortedContactsList = contactsList.sort((a, b) => {
  const timeA = a.lastMessage?.lastTime || 0;
  const timeB = b.lastMessage?.lastTime || 0;
  return timeB - timeA;
});

// 2. 匹配度计算方法
calculateMatchScore: function(keyword, contact) {
  let score = 0;
  const lowerKeyword = keyword.toLowerCase();
  
  // 匹配名称
  if (contact.name) {
    const lowerName = contact.name.toLowerCase();
    if (lowerName === lowerKeyword) {
      score += 100; // 完全匹配
    } else if (lowerName.startsWith(lowerKeyword)) {
      score += 80; // 开头匹配
    } else if (lowerName.includes(lowerKeyword)) {
      score += 60; // 包含匹配
    }
  }
  
  // 匹配最后一条消息
  if (contact.lastMessage) {
    const lowerMessage = contact.lastMessage.toLowerCase();
    if (lowerMessage.includes(lowerKeyword)) {
      score += 40; // 消息包含匹配
    }
  }
  
  // 匹配申请消息（针对待处理申请）
  if (contact.message) {
    const lowerMessage = contact.message.toLowerCase();
    if (lowerMessage.includes(lowerKeyword)) {
      score += 40; // 申请消息包含匹配
    }
  }
  
  return score;
}
```
